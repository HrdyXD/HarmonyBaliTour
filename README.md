# Harmony Bali Tour - Landing Page

A responsive landing page designed for **Harmony Bali Tour**, a travel agency that offers various Bali tour packages. This project provides an informative and user-friendly interface for visitors to explore tour packages, view destination galleries, and contact the agency directly.

## Overview

The website is built using standard web technologies and aims to deliver an engaging experience for potential customers seeking travel services in Bali. It includes multilingual support, package listings, image galleries, and direct booking integration through WhatsApp.

## Features

* Responsive design for desktop and mobile devices
* Hero section with call-to-action button
* Tour package listings with detailed information
* Destination gallery section
* About Us section
* Contact form and embedded Google Maps
* WhatsApp integration for direct booking
* Bilingual support (English and Indonesian)
* Mobile-friendly navigation menu

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Google Maps Embed API
* WhatsApp Click-to-Chat

## Website Sections

* **Home** – Introduction and promotional banner
* **Tour Packages** – Collection of available Bali tour packages
* **Gallery** – Showcase of Bali destinations
* **Our Advantages** – Highlights of the services offered
* **About Us** – Company profile and background
* **Contact** – Contact information, map location, and inquiry form

## Tour Packages

The website includes several travel packages, such as:

* Bali 1 Day Package (Uluwatu Tour)
* Bali 2 Days 1 Night Package
* Bali 3 Days 2 Nights Package
* Bali Honeymoon Package
* Bali Family Package
* Bali Private Tour Package

Each package provides information regarding duration, destinations, facilities, and pricing.

## Getting Started

1. Clone this repository.

```bash
git clone https://github.com/yourusername/harmony-bali-tour.git
```

2. Navigate to the project directory.

```bash
cd harmony-bali-tour
```

3. Open `index.html` in your preferred web browser.

No additional installation or dependencies are required.
